# root_gnn
RNN-based classification for reconstructed HEP events, specifically optimized for tau identification.

## Installation
```bash
conda create --name train_rnn python=3.7
conda activate train_rnn
conda install -c conda-forge root

git clone https://github.com/xju2/root_gnn.git
cd root_gnn
pip install -e .
```

## Workflow Overview
The pipeline consists of three main stages:
1. Data Preparation: Converting ROOT files to NPZ format and splitting into train/validation sets
2. Model Training: Training the RNN model using Keras
3. Inference and Evaluation: Applying the model and generating performance metrics

## NOTE: All of the following is already set up in one pipeline.
Simply submit a batch job with submit.slurm (a file in the 'batch_submissions' directory).

## Data Preparation
The data preparation step converts ROOT files to NPZ format and splits them into training and validation sets:

```bash
create_npz <input_root_file> <output_prefix> [--signal] [--inclusive]
split_npz <input_npz_file> <validation_fraction>
```

Example:
```bash
# Convert ROOT files to NPZ
create_npz ditau_train_final2.root ditau --signal --inclusive
create_npz qcd_train.root qcd --inclusive

# Split into train/validation sets (20% validation)
split_npz ditau_inclusive.npz 0.2
split_npz qcd_inclusive.npz 0.2
```

## Training
The training process uses a Keras-based RNN model. Training can be initiated using:

```bash
train_keras <signal_npz_file> <background_npz_file> --model-path <output_path> -l <signal_weight>
```

Example:
```bash
train_keras ditau_inclusive_train_val.npz qcd_inclusive_train_val.npz --model-path ./model -l 10
```

## Inference and Evaluation
The trained model can be applied to test data and evaluated using:

```bash
# Apply model to test data
apply_keras <model_path> -i <test_npz_file> -o <output_npz_file> -l <signal_weight>

# Generate performance plots
plot_tauid <output_directory>
```

Example:
```bash
# Apply to test files
apply_keras ./model -i ditau_inclusive_test.npz -o inclusive_ditau.npz -l 5
apply_keras ./model -i qcd_inclusive_test.npz -o inclusive_qcd1.npz -l 5

# Generate performance plots
plot_tauid ./inclusive
```

## Batch Submission
For running the complete pipeline on a cluster, a SLURM submission script is provided. The workflow can be executed using:

```bash
sbatch submit.slurm
```

This will run the complete pipeline:
1. Data preparation
2. Model training
3. Inference
4. Performance evaluation

## Model Architecture
The current implementation uses a Keras-based RNN model optimized for tau identification. The model takes as input:
- Node features from reconstructed particles
- Edge information between particles
- Global event information

The model outputs a classification score for each event, distinguishing between signal (tau) and background (QCD) jets.

## Performance
The model's performance can be evaluated using:
- ROC curves
- AUC scores

These metrics are automatically generated by the `plot_tauid` command.
